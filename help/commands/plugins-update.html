Vigil Help/Plugins

plugins:update

Update a locked extension from a local file or signed index.

Writes files/stateNetwork optionalStableTimeout: 2 minutes

Quick Start#

vigil --allow-mutation plugins:update --file ./vigil-plugin-example --approve-all

What It Does#

Works with digest-bound plugin state, local trust, repository policy, and the strict subprocess plugin protocol.

Plugin approval records a trust and capability decision. It is not an operating-system sandbox.

Uses standard Vigil global flags and exit-code conventions.

Outcomes#

  • Success returns exit code 0.
  • Usage or configuration errors return exit code 2.
  • Policy blocks, missing tools, cancellation, mutation violations, and internal failures use Vigil's stable exit taxonomy.

Examples#

Run documented example

Example declared by the active command contract.

vigil --allow-mutation plugins:update --file ./vigil-plugin-example --approve-all

Return structured JSON

Returns a stable Vigil output envelope.

vigil --allow-mutation plugins:update --json

Syntax#

Usage: vigil --allow-mutation plugins:update (--file PATH|--index SOURCE --id ID --version VERSION) [--approve ACCESS ...|--approve-all]

Flags

FlagValueDescription
--jsonPrint structured JSON output.
--filePATHChoose a local extension executable.
--indexSOURCEChoose a signed index path or HTTPS URL.
--idPLUGIN_IDRequire an exact extension id.
--versionVERSIONRequire an exact semantic version.
--digestSHA256Require an exact SHA-256 executable digest.
--approveACCESSApprove one declared access request.
--approve-allApprove every declared access request.
--restore-trustRemove a matching local digest revocation.
