checks:public-assumptions

Scan public Vigil source for product-specific assumptions.

AccessRead-only
SourceCore command
Networknone

Syntax#

vigil checks:public-assumptions [args]

Options#

FlagDescription
--jsonEmit the versioned JSON envelope.
--formatSelect a machine or human output format.

Examples#

vigil checks:public-assumptions
vigil checks:public-assumptions --json

Example Use Cases#

  • Use this command when you need to scan public Vigil source for product-specific assumptions.
  • Run it in local checks, scripts, or CI when read-only evidence is needed.
